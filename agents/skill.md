# Fort docs

Fort runs autonomous AI agents inside a company's own cloud. Each agent gets a sandbox;
Warden checks every tool call against policy and answers allow, ask a person, or deny;
every decision goes into a tamper-evident ledger. Fort is pre-launch and in early access.
